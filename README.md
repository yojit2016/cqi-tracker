# CQI Tracker UI

Frontend internship project for tracking Continuous Quality Improvement (CQI) activities within an Outcome-Based Education (OBE) system.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Chart.js

## Current Status

- Week 1 Complete
- Week 2 Foundation Started

## Features Implemented

- Dashboard Shell
- Sidebar Navigation
- Navbar
- KPI Cards
- Theme Toggle
- Responsive Layout
